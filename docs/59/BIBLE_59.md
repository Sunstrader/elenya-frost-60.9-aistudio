# Bible — précisions 59.0.0

- **Primaëlys** est le nom du lieu dans tout le texte visible. **PRYMAËLIS** n’apparaît que gravé sur la porte de la mine : c’est l’ancienne graphie. Les gardiennes prenaient le nom du lieu qu’elles gardaient : le lieu, la gardienne et le territoire portent donc le même nom, par tradition et non par erreur.
- **Couleurs** : ambre = transe (la relique, la Larme, s’allume) ; bleu = Kalthar. Fen n’a pas d’yeux ambrés ; Oraya n’a pas d’yeux bleus dans les indices.
- **Fen** ne rend pas la mémoire : il est présent quand elle revient. Aucun lien Fen = Kalthar n’est dit avant ACTE4_07_ADIEU_KALTHAR / FEN_ADIEU.
- **Oraya** n’est ni nommée ni reliée à la stèle avant FRAGMENT_4_STELE (indices 1 à 3 muets sur ce point).
- **Ordre du Soleil / Inquisition** : l’Inquisition est le bras armé de l’Ordre.
- **Venin** : délai de 7 jours à l’entrée d’URGENCE_NARRATIVE.
